# HD Model Platform, published site

This repository holds only the built, static output of the HD Model Platform site and is overwritten on every deploy. Do not edit it by hand: changes are made in the source repository and published from there after its tests pass.

Live site: https://evan-kun.github.io/hd-platform-web/

Browser-based research demonstrations of published Huntington's disease machine-learning models from the Nellie Georgiou-Karistianis Lab, Turner Institute for Brain and Mental Health, Monash University. Everything runs in the visitor's browser; no cohort data is in this repository.
